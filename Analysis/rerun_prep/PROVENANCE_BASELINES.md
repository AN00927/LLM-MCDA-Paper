# Provenance of the no-LLM baselines

Written 2026-09-25 (P2). Covers every constant and rule of the dataset-median condition
(`Miscellaneous Scripts/experiments/run_hybrid_ablation_experiments.py`, abbreviated `HAB`) and of
the four baselines in `Miscellaneous Scripts/core-automation/run_baseline_models.py` (abbreviated
`RBM`): fixed default, nearest neighbour, random and uniform. Line numbers are for the files as they
stand after the P2 changes and the 2026-09-26 follow-ups. Sources come only from the code comments, `paper/paper_draft_v2.tex`
(main), `paper/supplementary.tex` (S) and `paper/CALCULATOR_AUDIT.md`. No web search was done. A
value with no recorded source is marked `our assumption`.

"Homeowner field" means a value the Test sheet shows the LLM (location, household size, budget,
housing type, floor area, outdoor temperature, the age and flow-rate bands). "Hidden parameter" means
one of the values A_H has to estimate (`HAB` `HIDDEN_PARAMS`, L167).

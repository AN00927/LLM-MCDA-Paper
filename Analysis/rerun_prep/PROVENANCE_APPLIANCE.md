# Provenance: Appliance reference calculator (new)

as of 2026-09-25, after the price-to-compare basis change). Built only from sources already read
this session and from the quotes recorded in `paper/CALCULATOR_AUDIT.md` (Appliance section) and
`paper/pass5/PASS5_PROPOSAL.md` Part B. Nothing was re-fetched. Where no source is known the row
says `our assumption`; a redundancy pass comes later.

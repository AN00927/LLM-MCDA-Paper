# Provenance: HVAC reference calculator (new)

File: `Analysis/rerun_prep/calc_new/HVACGroundTruthCalculator.py` (line numbers below refer to it,
revision 2 of 2026-09-25: operating mode from the question, occupant gain 220 Btu/h, continuous
budget penalty). Built from sources already read in the P1-HVAC session and the quotes recorded in
`paper/CALCULATOR_AUDIT.md` (HVAC section) and Part B of `paper/pass5/PASS5_PROPOSAL.md`. No source
was re-fetched for this file. "Quote not recorded" means the value was checked in an earlier pass
but no verbatim line was kept; those rows need the quote added in the redundancy pass.

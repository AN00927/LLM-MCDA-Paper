# Calculator provenance

Merged record of what each constant in the three reference (ground-truth) calculators and the
no-LLM baselines is based on: where it lives in code, what source backs it, the verbatim quote
supporting it, and whether it is `sourced` (a primary document says this value), `derived` (computed
from sourced inputs by a stated rule), or `our assumption` (no source found; a modelling choice made
by the authors). Per `paper/pass6/CLOUD_AGENT_CONTEXT.md`: "any change to a calculator or baseline
constant updates its provenance entry ... The merged record is `docs/CALCULATOR_PROVENANCE.md`."

This file merges four source documents, each written by a separate verification pass:
`Analysis/rerun_prep/PROVENANCE_HVAC.md`, `PROVENANCE_APPLIANCE.md`, `PROVENANCE_SHOWER.md` and
`PROVENANCE_BASELINES.md`. Those files are kept (not deleted) as the pass-level record; this file is
the one CLOUD_AGENT_CONTEXT.md and CLAUDE.md point to as the standing reference. Code locations below
point at `Ground Truth Calculators/<File>.py`, the installed/shipped location, not at the staged
`Analysis/rerun_prep/calc_new/` copies the source documents were originally written against — the
files are byte-identical (`calc_new/{HVAC,Appliance,Shower}GroundTruthCalculator.py` are being
installed to `Ground Truth Calculators/` under the same filenames as part of the same rerun-prep
pass this document was written in). **Line numbers were independently re-verified against the current
file contents while merging** (2026-09-27), not copied blindly from the source documents; where a
source document's line number had drifted or was wrong, it is corrected here and flagged. See "Open
items" at the end for every place code and a source provenance document disagree.

Status legend: **sourced** = a primary document states the value directly (verbatim quote given).
**derived** = computed from sourced or physical inputs by a stated, checkable rule. **our assumption**
= a modelling choice with no external source; the paper and CLAUDE.md still commit to it, but no
document backs the specific number. A blank "Previous source" cell means the row is unchanged from
an earlier documented value, or is new.

# Calculator provenance

Merged record of what each constant in the three reference (ground-truth) calculators and the
no-LLM baselines is based on: where it lives in code, what source backs it, the verbatim quote
supporting it, and whether it is `sourced` (a primary document says this value), `derived` (computed
from sourced inputs by a stated rule), or `our assumption` (no source found; a modelling choice made
by the authors). Any change to a calculator or baseline constant should update this public
provenance record alongside the code.

This document consolidates the calculator and baseline provenance reviews into one standing
reference, alongside `CLAUDE.md`. Code locations below point to the calculator modules under
`src/llm_mcda/calculators/`. **Line numbers were independently re-verified against the file contents
on 2026-09-27**; where earlier records had drifted or were wrong, the current locations are given here.
See "Open items" at the end for remaining source and verification limitations.

A full provenance check of every row was completed on 2026-09-27 against the primary sources and the
then-current code. The author approved changes A1-A8 (installed in commit `95d7fce`); this record also
incorporates the review's line-number corrections, missing quotes, and re-citations. Every code-location
cell below was checked against the file contents after that change.

Status legend: **sourced** = a primary document states the value directly (verbatim quote given).
**derived** = computed from sourced or physical inputs by a stated, checkable rule. **our assumption**
= a modelling choice with no external source; the model configuration records the chosen value, but no primary
document supports the specific number. A blank "Previous source" cell means the row is unchanged from
an earlier documented value, or is new.

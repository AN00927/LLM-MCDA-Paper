\section*{Highlights}
\begin{itemize}
  \item Bridges natural-language user inputs to rigorous physics-based decision models.
  \item Hybrid LLM-physics framework achieves $\tau$ of 0.88--0.92 and 90--93\% Top-1 accuracy.
  \item Direct and RAG scoring fail near chance ($\tau = 0.01$--$0.31$), lacking physics laws.
  \item Physics calculators narrow model capability gap 4$\times$ while cutting costs up to 8$\times$.
  \item Open-source framework scales rapid, expert-grade decarbonization decision support.
\end{itemize}
